# Roadmap

Updated: 2026-09-20

## Native 0.5.0 development

User-confirmed session budgeting is implemented alongside weekly/five-hour reads, reset-credit deadlines, local history and multilingual UI. See [scope](mvp-scope.md) and [acceptance](acceptance-criteria.md). Distribution remains subject to release gates.

## Next improvements

1. Multiple daily work sessions and per-day schedules.
2. Optional user feedback about holding back, and local records of advice actually viewed.
3. Evaluate useful work, leftovers and interruptions prospectively before claiming behavioral improvement.
4. Better account-data coverage and portable, opt-in plan/history synchronization.
5. Port the verified session planner to the browser lab; then assess Chrome demand.
6. Signed and notarized macOS distribution, followed by other platforms/providers when supported.

Automatic habit inference must distinguish unknown sampling intervals from inactivity. Automatic reset-credit redemption and task/model control remain outside the current product scope.
