# 给同事介绍 Quota Capsule

更新：2026-09-20

Quota Capsule 是一个面向 Codex 的 macOS 额度工具。它显示周额度、5 小时限制和重置券截止时间，并把剩余周额度分给你计划工作的时段。

这次 0.5.0 源码更新关注一个常见问题：看到“可能不够用”的提示后，人会主动减速，随后记录下来的低消耗就不能代表他原本想做多少工作。因此主界面改为使用计划：确认工作时间和预留额度，得到固定的本段分配，实际用量再从里面扣。睡觉等未安排时段不分额度；历史速度放到参考区域。

和单纯展示百分比相比，新增的价值是“这段时间可以安排多少额度”。这是一种产品选择，不能据此宣称优于所有竞品，也尚未证明能减少多少浪费。

设置和计算在本地，跨设备消耗体现在账号累计读数中，但缺失的采样不能准确还原活动时段。应用不会自动使用重置券。

当前源码与下载版可能不同。请按 [Releases](https://github.com/Bono12138/codex-quota-capsule/releases) 的具体说明安装；旧版 v0.3.6-beta.1 尚不包含时段预算。
