# v0.3.6-beta.1 Release Evidence

Status: published public prerelease
Updated: 2026-08-07

## Incident and scope

- The `v0.3.5-beta.1` executable exposed the builder's private macOS username and absolute checkout/build paths through SwiftPM resource fallback code and linked debug information.
- No API key, token, cookie, private Codex content, local quota database, or private repository address was found in the tracked source or published package.
- The project email, X account, Douyin account, QR code, and public author names were reviewed and approved for public use by the maintainer.
- The unsafe `v0.3.5-beta.1` ZIP was removed before the corrected release was published. Its Release page remains as a historical withdrawal notice with no downloadable assets.

## Repair

- The packaged application now loads its approved images only from `Contents/Resources`; SwiftPM no longer generates an absolute build-directory resource fallback for the macOS executable.
- The source-tree `#filePath` fallback was removed.
- Release debug information is stripped before the application is signed.
- Packaging scans the signed application and a fresh ZIP extraction for macOS, Linux, and Windows user-home paths. Failures identify the affected artifact without printing the private username.

## Automated verification

- Node/Vitest: 126 tests passed, including three release-artifact privacy regressions.
- Swift: 112 tests passed.
- TypeScript build and lint passed.
- `QuotaCapsuleCoreSpec`, repository policy, Weekly Only audit, Swift product build, archive integrity, signature verification, and `git diff --check` passed.
- The privacy regression failed before the scanner existed, and the real packaging command failed until both the generated SwiftPM resource path and linked debug paths were removed.
